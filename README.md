# Java Programming 1 – Course Projects

## Description
This repository contains my projects and assignments from the *Programming 1* course, where I learned the fundamentals of Java and the basics of problem‑solving.  
The work focuses on understanding Java syntax, writing simple programs, and applying core programming concepts through small exercises and console-based applications.

## Technologies Used
- Java
- Basic OOP concepts
- IDE NetBeans

## Contents
- Introduction to Java Syntax
- Variables and Data Types
- Input and Output (Scanner)
- Conditional Statements (if, else-if, switch)
- Loops (for, while, do-while)
- Methods and Parameter Passing
- Arrays and Array Manipulation
- Simple Object-Oriented Programming (Classes & Objects)

## Learning Outcomes
- Understanding the structure of a Java program
- Writing clean and organized code using basic programming constructs
- Applying logical thinking to solve beginner-level problems
- Using loops and conditions to build interactive console applications
- Gaining initial exposure to object‑oriented programming

## How to Run
1. Open the project folder in your preferred Java IDE.
2. Ensure JDK is installed.
3. Run the `.java` files from the main class of each assignment.

## Notes
These projects were completed as part of my university coursework and represent my first steps in learning programming and Java fundamentals.
